# Asset and data attribution

Retrieved November 2, 2026. All application code, chapter summaries, SVG chapter
landscapes, shaders, and synthesized audio in this repository are independently
authored. The reference site's proprietary code, prose, and unknown-license
videos are not included.

`public/assets/clouds.jpg` is NASA Blue Marble's
[global cloud composite](https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57747/cloud_combined_2048.jpg),
used under the same NASA educational imagery guidelines as the surface texture.
It is a modern cloud-pattern illustration at every historical age, not a
paleoclimate cloud reconstruction.
